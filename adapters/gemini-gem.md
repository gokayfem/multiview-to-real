# Gemini (Gem)

1. Create a Gem and paste `adapters/universal-system-prompt.md` (the part below the line) into its instructions.
2. Add `skills/multiview-to-real/SKILL.md`, `references/generation.md`, `references/seams.md` and
   `references/lessons.md` as files.

For Gemini CLI, install the extension instead:
`gemini extensions install https://github.com/gokayfem/multiview-to-real`.
